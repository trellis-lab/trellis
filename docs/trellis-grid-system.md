# Trellis Grid system

The trellis system is using a grid system to draw nodes and orthogonal edges among them.
The nodes and edges are snapped to the grid lines.
The number of rows and columns of the grid aare calculated during the diagram rendering pipeline.
The grid cell is always a square.
I.e., the width and the height of the grid cells are the same.
The grid cell size is an integer value and also calculated by the pipeline.

The grid points can be identified by their row and column indexes.
The 0,0 grip point is the top-left one.

## Nodes

The positioning of the nodes are relying to the grids because the top; left corner of the node's rectangle must be aligned to a grid point.
The width and height of the node rectangles must be integer multiplier of the cell size.
The minimum width of the node rectangle is 5 * grid_cell _size.
The minimum height of the node rectangle is 3 * grid_cell_size.
The grid points on the edges of the node rectangle are the connector points of the given node, except the four corners.
So, the minimum sized node rectangle has 8 connector points.
There 3-3 on the longer edge and 1-1 on the short edge.

## Edges

The edges have orthogonal drawing and the vertical and horizontal segments of the edge must be on the grid lines.
The corner of the edges are rounded by default.
The edges are always connected to a connector point of the source node and a connector point of the target node.
